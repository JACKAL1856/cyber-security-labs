Cyber Security Labs

This repository contains hands-on web application security labs with detailed technical reports, covering beginner to advanced attack techniques. The work focuses on practical security testing, analysis, and documentation aligned with industry practices.

Repository Structure

Beginner Web Security
• Reconnaissance
• Port scanning
• Directory enumeration

Intermediate Security
• Encryption analysis
• Executable inspection
• Fundamentals of reverse engineering

Advanced Web Attacks
• SQL injection
• Cross-site scripting (XSS)
• Authentication bypass techniques
• Real-world web attack simulations

All testing activities documented in this repository were performed exclusively in authorized and intentionally vulnerable lab environments for educational and skill-development purposes.
